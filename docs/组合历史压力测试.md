# 组合历史压力测试沙盘

本轮将现有 Agent 接到一个有实际用途、可复算的研究工具。它回答的是：

> 用我的当前配置，重演本地过去一年里最差的连续 20 个共同观察日，会怎样？换个配置，在同一段行情里有什么不同？

## 页面测试

1. 打开 `http://127.0.0.1:8000/#portfolio/stress`，选择已保存的组合。
2. 默认“近1年 / 20日”，点击“重演历史行情”。支持近6个月、1年、3年及20、40、60个观察日。
3. 页面应显示一个历史日期区间、原配置的收益和回撤、起点100的模拟曲线，以及各基金的收益贡献。
4. 修改候选权重，合计必须为100%。点击“比较配置”后出现第二条曲线和两份结果的差异。比较不修改真实持仓，也不为候选方案重选行情。
5. 点击“复算核对”，应显示“复算一致”。这仅表示相同输入和版本可以复算，不表示行情真实或预测正确。
6. 刷新浏览器后点击“历史记录”，从下拉框读取旧报告。读取、复算、比较都不更新行情；需要新行情时仍通过原有手动同步入口完成，再新建情景。
7. 点击“AI 解读”会把报告编号带到现有聊天输入框，确认发送才调用 DeepSeek。

若提示共同净值不足或没有完整窗口，补齐相应基金的本地数据，或改用较短窗口。不会用虚构净值填补缺口。实际样本截止时间与请求的“近一年”不是一回事，数据可能滞后，详情会显示真实日期。

## 自然语言测试

在 AI 助手选择组合上下文，然后发送：

```text
请对当前组合做历史压力测试，找出过去一年里最差连续20个观察日，解释哪个基金拖累最大。
```

看到实际基金代码和原权重后，明确给出全部基金的候选权重，例如：

```text
继续沿用刚才的压力情景，把110020设为30%，161725设为20%，110007设为50%，比较一下。
```

示例代码必须替换成该报告包含的基金。本轮只支持原基金集合内调整，不支持直接添加新基金或现金。只说“减一点半导体”却没说资金转到哪里时，Agent 应追问，不该自行决定。

模型只负责理解参数和解释结果；Python 负责计算。报告编号由实际工具回执追加到会话，不依赖模型记住输出它。近期上下文丢失时应选择历史记录，不应偷偷切到另一个会话的最新报告。尚未增加压力测试专属的生成文本事实校验器，解释仍需结合报告核对。

## 工作流

```text
页面按钮 / 用户消息
  -> REST / 现有 Agent Loop + 两个受限工具
  -> PortfolioStressService
  -> 新情景：读取现有组合和本地基金回报序列，冻结输入
     比较：按用户与组合读取原记录，不再读最新行情
  -> LangGraph：select_window -> simulate
  -> SQL 保存报告、根记录引用和 SHA-256
  -> 前端 ECharts 曲线 / Agent 解释
```

## 计算口径

基金日收益来自项目已有的回报指数，默认优先使用分红再投资口径；具体降级口径见每只基金的来源信息。基金缺日时不向前填充。若某个共同日期间隔中另一基金存在额外日期，则相应跨日收益不能当成一天参与连续窗口。所有来源共同漏日仍无法识别，因此称“共同观察日”，不是官方交易日历认证。

设基金日收益是 `r[t,i]`，权重是 `w[i]`（小数形式，合计1）：

```text
组合日收益 p[t] = sum(w[i] * r[t,i])
模拟资产 V[0] = 1
模拟资产 V[t+1] = V[t] * (1 + p[t])
区间累计收益 = (V[末日] - 1) * 100%
最大回撤幅度 = max(1 - V[t] / max(V[0:t])) * 100%
基金i的区间收益贡献 = sum(V[t] * w[i] * r[t,i]) * 100 个百分点
```

贡献按每天期初资产计算，未舍入前各基金贡献之和等于区间复利收益。不是简单的“权重乘基金整段涨跌幅”。

先用**原配置区间累计收益最低**选窗口，不是用最大回撤选窗口。所有窗口都上涨时，选择涨得最少的一段，不能编造亏损。相同窗口收益在极小浮点容差内选择最早者。

当前配置被应用到过去行情，采用每日再平衡近似；手续费、税费、申赎限制不纳入。这不是账户流水回测，不存在收益保证，也不能把降低这一个窗口的亏损说成所有市场下都更优。

## 持久化与边界

- 根记录保存完整冻结矩阵；比较记录只保存根ID和计算报告，复用相同输入指纹。
- 所有读取按 `user_id + portfolio_id + run_id` 校验。HTTP用户身份及工具执行身份仍遵守现有权限链。
- `(user_id, idempotency_key)` 唯一约束防并发重复记录。相同请求编号不能用于不同参数。
- 两个 LangGraph 节点是快速的确定性计算，不是新的后台 Job；没有宣称能从一半算术运算处断点恢复。失败可幂等重试，完成记录可重启后读取和复算。
- 此版逐个读取本地来源后冻结输入，不宣称多个来源在同一数据库事务中同时采样；记录了捕获起止时间。
- 本地自动建表模式会创建新表；关闭自动建表的工程模式按既有流程运行 `alembic upgrade head`。新迁移为 `d104a78e6b20`，不修改原组合表。
