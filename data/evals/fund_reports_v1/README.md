发布版的 `manifest.json` 记录来源、哈希、不可变文档 ID 和解析事实，不包含逐页原文。
先运行 `python -m scripts.prepare_report_fixtures`，按来源下载并核对哈希后生成本地
`documents.json` 与 PDF；这两类生成文件不纳入 Git。
数值参考答案独立录入 `../fund_report_rag_v1.json`，评分不从算法本次输出生成标准答案。
标注已由编码助手对照原文整理，尚需项目所有者人工验收。

维护规则：不要把“最新季报”覆盖到这里；新季度或改动题目应制作新版考卷。重复运行先核对 PDF
哈希和物理页文本。文档指纹变化后，不与旧数据混算回归分数。

这些公开报告不是项目原创，不为第三方报告授予新的许可；若准备公开分发仓库，需另行核对
原始文档的转载条件，或仅发布来源清单与下载脚本。此目录不含用户持仓或登录信息。

用法、指标边界和已发现问题见 [季报评测说明](../../../docs/基金季报RAG评测.md)。
