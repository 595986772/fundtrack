# 小程序金融业务功能对齐

## 页面对应

| 网页模块 | 小程序入口 | 操作与结果 |
| --- | --- | --- |
| 资产 / 持仓、配置、交易 | 资产；基金详情、持仓录入、记账 | 同一账号、同一数据库。按份额与成本管理，不自动将分析方案变成交易。 |
| 资产 / 业绩、风险、事件 | 资产 → 对应分析按钮 | 同样的后端计算与数据日期；分析详情独立打开。 |
| 压力测试 | 资产 → 压力测试 | 选择样本和连续窗口；查看历史报告；候选权重合计100%；同一冻结样本对比及复算。 |
| 约束求解 | 资产 → 约束求解 | 自然语言转草案，用户核对三个数值条件后显式确认；未支持条件或空白不能直接求解。 |
| 风险监控 | 资产 → 风险跟踪 | 立即运行、读取预警、标记已读、保存阈值与已有定时策略；仅打开页面不启用定时任务。 |
| 事件列表、热点追踪 | 事件情报 → 事件列表 / 热度变化 | 筛选数据库记录；展开“采集与分析”才发起数据采集、模型处理或聚类。 |
| 社区话题、样本、观点复核 | 社区热点的三个分段视图 | 读取已保存正文、图片、OCR及作者去重结果；采集与复核按钮各自确认，平台阻断时不绕过。 |
| 板块概览 | 板块雷达 | 同一套主题名称归并；关联已保存热点和资金证据，不虚构“未来涨幅”评分。 |
| 市场环境、资金、情绪 | 板块雷达 → 各二级入口 | 指数、全市场成交、日曲线、1/5/20日板块资金、民间情绪指标及各自来源局限。 |
| Agent 聊天 | AI投研 | 历史会话、单基金/账本/市场对象、阶段进度、回答与证据、取消；默认不补抓公开数据。 |
| 多视角研判 | AI投研 → 多视角研判草稿 | 填入问题，用户发送后由已有 Agent 判断工具调用；不是前端拼接虚构的多个 Agent 答案。 |
| 研究报告及审计比较 | AI投研 → 研究报告 | 读取历史报告、生成新任务、与上次比较、查看模型与冻结证据。 |
| 调整方案人机确认 | 已完成研究报告 → 生成调整方案 | 后台运行至等待确认；核对风险偏好、期限、换手等约束后继续，或取消；结果只供研究。 |
| 决策记录与复盘 | AI投研 → 决策记录 | 保存当时理由、观察期限，读取后续表现、保存复盘与删除记录。 |

小程序没有复刻桌面端的拖拽、多列密集图表布局，也没有迁移开发者管理台。共享报告展示器使用明确的中文业务字段映射，不把原始 JSON、未知内部字段或完整收益矩阵堆到手机页面。

## 不变的边界

- 打开页面、切换视图、搜索已保存记录只读取现有数据。采集和模型操作由用户明确触发。
- 数据日期来自服务器，不能把请求发生时间当行情时间。净值、机构披露、情绪数据不是保证实时的同一种数据。
- 小红书扫码/验证仍在后端 Mac 上完成。手机界面不能解除平台警告，也不会自动重试绕过验证。
- 宝妈指数等缺少可用来源时仍显示缺口；不因为迁移页面就制造数据。
- 任务编号和未完成提交按服务器及用户隔离；失败重试复用幂等编号。查询进度失败不会重复启动采集或研究。
- AI 分析会使用后端配置的真实模型，可能产生费用。测试中的模型和写入用替身，不以假回答充当真实模型验收。
- 原生微信与浏览器预览共享业务逻辑，但网络、Canvas、键盘和流式回调还需在微信真机验收。

## 手机上怎么验收

1. 构建后在微信开发者工具重新编译并预览扫码，确认底部为五个入口。
2. 从任一主页面右上角“设置”核对后端地址与账号。手机使用 Mac 局域网地址，不填 `127.0.0.1`。
3. 资产页选择已有账本，进入业绩与风险页；核对金额、份额、数据日期与网页一致。此步骤不要新建测试交易混入真实账本。
4. 事件情报搜索“半导体”，展开筛选选择日期；打开一条事件看原文来源。打开“采集与分析”可分别处理已保存资讯，不必每次重新采集。
5. 社区热点切换三个视图，查看全部已保存样本和图片文字。出现平台验证提示时停止采集，仅验证已有记录的显示。
6. 板块雷达进入市场环境、日成交额曲线，切换市场和30日/3个月；缺数据应明确显示状态，不应补成零。
7. AI投研选择“市场综合”，问“请基于已保存数据概括当前市场风险，不刷新数据”。检查阶段进度、最终答案只出现一次，再追问并重进页面验证历史会话。
8. 从资产页进入压力测试运行一次，调整候选权重后对比。再进入约束求解输入要求，核对草案并确认。两者都不应修改实际持仓。
9. AI投研生成研究报告，离开页面再回来检查同一任务；完成后打开调整方案，确认它先暂停等你确认，不能直接执行交易。

本轮自动化覆盖：SSE中文拆包/异常/重复结果、账号切换丢弃旧响应、幂等任务、只读入口、平台暂停、约束确认、非法权重、空数据模板、原有资产与基金导入流程；后端覆盖身份解析和兼容路由。真实模型质量、微信实际网络及平台采集可用性不由这些离线测试保证。
