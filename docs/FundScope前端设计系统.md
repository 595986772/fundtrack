# FundScope 前端设计系统

## 目标

FundScope 是面向个人基金研究的工作台。界面优先帮助用户回答三个问题：

1. 我的组合现在处于什么风险状态？
2. 当前市场环境和重要事件是什么？
3. 哪些结论可以继续交给 AI 深挖？

设计参考 Wealthfolio 的投资信息层级、shadcn/ui 的开放组件结构和
assistant-ui 的对话线程布局，但不直接复制第三方项目源码。

## 信息架构

一级工作区固定为四个：

- `总览`：组合风险、市场状态、事件数量和关注基金。
- `组合`：持仓录入、配置分析、风险研判、监控和 LangGraph 工作流。
- `市场`：量化市场状态、新闻政策、语义处理状态和数据来源。
- `AI 助手`：会话历史、上下文、流式回答、证据和工具运行结果。

基金列表是跨工作区的研究上下文，不再承担一级导航职责。点击基金后回到总览，
展示该基金的净值、风险、披露和证据详情。

## 视觉令牌

设计令牌定义在 `app/static/design-system.css` 的 `:root` 中：

- `--canvas`：页面背景，只负责建立层次。
- `--surface`：可交互工具和数据表面的白色背景。
- `--ink / --muted / --faint`：三级文字颜色。
- `--accent`：主操作、当前导航和正向状态。
- `--blue`：中性数据和量化指标。
- `--amber`：谨慎、待确认或混合状态。
- `--danger`：风险、失败和负面状态。
- `--border / --border-strong`：普通边界和交互边界。

圆角统一控制在 `6-8px`，阴影只用于总览信号、组合工具和输入框等真正需要
建立前后层级的位置。

## 组件规则

- 一级导航使用左侧垂直导航，当前项由背景和左侧状态线共同表示。
- 图标按钮必须有 `title` 和 `aria-label`，有明确命令时使用图标加文字。
- 风险结论优先显示状态、证据摘要和数据日期，不用颜色单独传达含义。
- 页面区块保持完整宽度；卡片只用于基金、指标、事件等可重复数据单元。
- AI 回答保持无边框阅读流，用户消息使用轻量背景，输入框固定在内容底部。
- 正文字号不低于 `11px`，核心结论使用 `17-31px` 的明确层级。

## 响应式规则

- `> 1180px`：完整侧栏和宽屏研究工作台。
- `761-1180px`：收窄侧栏，开发者检查器改为浮层。
- `<= 940px`：总览改为单列，基金卡片改为两列。
- `<= 760px`：侧栏改为抽屉，总览指标和基金卡片改为单列。

移动端必须保持 `document.scrollWidth === viewport width`，不能出现横向滚动。

## 工程边界

当前业务前端包含大量已经测试过的原生 JavaScript 渲染逻辑，因此本轮采用渐进式
重构：

- `styles.css` 暂时保留历史业务组件样式。
- `design-system.css` 统一产品外壳、令牌和新版组件。
- `app.js` 增加工作区路由和总览状态聚合，不重复调用后端接口。
- FastAPI API、SSE 流式协议和后台任务逻辑保持不变。

后续迁移 React 时，优先迁移无写操作的总览和市场页，再迁移组合表单，最后使用
assistant-ui 替换 Agent 消息线程。每迁移一个页面，都保留现有 FastAPI 契约测试。
