# FundScope 市场状态冻结快照

这里保存市场情绪上下文层使用的离线数据。正常启动和测试只读取本目录，
不会临时访问财经网站。

`market_snapshot.json` 包含：

- 2026-08-25 全市场上涨、下跌、平盘和涨跌停家数；
- 沪深300指数最近 5 个交易日成交额；
- 用于计算趋势和波动的宽基代理基金代码 `110020`。

`market_events.json` 包含 8 条人工冻结、逐条可追溯的官方事件样例：

- 消费数据与扩大消费政策；
- 白酒产业政策、市场监管和基金溢价风险公告；
- 资本市场政策与国债发行公告。

事件加载时会统一日期格式，并对规范化后的来源文本计算 SHA-256。相同哈希的
重复采集记录只保留一条。来源等级中，A 表示发布主体或监管部门官方来源，B 表示
政府转载或地方权威来源，C 预留给媒体和第三方研究来源。

原始数据由 `scripts/freeze_market_fixtures.py` 通过 AKShare 从 Eastmoney 和
LeGuLeGu 获取。宽基趋势仍复用 `data/fund_fixtures/` 中已经冻结的净值。

这些数据只用于可重复的项目演示，不是实时行情，也不构成投资建议。
